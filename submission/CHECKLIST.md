# Submission handoff

Deadline: September 3, 2026 at 1:00 p.m. PDT = September 4, 2026 at 1:30 a.m. Asia/Kolkata.

1. Register at https://webmcp.devpost.com/ and verify personal eligibility in the official rules.
2. Use the final public live app URL. Test signed out; a private owner-only Sites link is insufficient for judges.
3. Use the public GitHub repository URL. It includes MIT LICENSE, all source, and run instructions.
4. Paste the relevant fields from DEVPOST.md.
5. Upload the completed demo to YouTube as **Public**, with audio, under 3 minutes. Use DEMO-SCRIPT.md as the recording guide.
6. Add the live URL, public repository URL, and public YouTube URL to the Devpost submission.
7. Review the final entry and personally accept the hackathon terms and submit before the deadline.
8. Keep the demo accessible through the end of judging (September 21, 2026).

The app can be explored without an account or API key. WebMCP interaction requires a supported browser. There is no guaranteed prize; selection is competitive.

Authoritative requirements: https://webmcp.devpost.com/ and https://webmcp.devpost.com/rules . Checked September 3, 2026 IST.
